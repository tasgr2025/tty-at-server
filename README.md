# Имитатор AT-сервера

## Назначение файлов.

- `main.cpp` - текст программы сервера.
- `Makefile` - инструкция по сборке.
- `send-at-cmd.sh` - вспомогательный скрипт, позволяет отправлять
команды в модем и печатает ответ. Используется для теста.
- `test-dict.txt` - словарь контрольных команд и ожидаемых ответов для AT-сервера. Используется для теста.
- `dict.txt` - словарь команд для AT-сервера, описан в ограниченном наборе регулярных выражений (в соответствии с **ТЗ**). Используется для работы AT-сервера.
- `install-deps.sh` - скрипт для установки зависимостей необходимых для сборки.
- `test.sh` - скрипт для проведения теста:
    - создаёт связанные последовательные порты;
    - запускает AT-сервер;
    - выполняет подачу команд AT-серверу;
    - проверяет ответ AT-сервера;
    - выводит итоговый результат теста.
- `virtual-serial.sh` - создаёт связанные последовательные порты. Используется для теста.

## Сборка

- убедиться, что все необходимые зависимости установлены, для чего запустить скрипт `install-deps.sh`
- в папке проекта выполнить команду `make`

## Проведение теста

- Установить флаг `исполняемый` у файлов bash-скриптов.
  Для этого выполнить команду: `chmod +x *.sh`
